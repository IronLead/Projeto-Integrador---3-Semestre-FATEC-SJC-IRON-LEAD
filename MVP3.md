# 📌 MVP - [Sprint 03]

## 🎯 Objetivo do MVP
<p align="justify"> Transformar os dados já consolidados e validados em informações estratégicas por meio da criação de indicadores logísticos e modelos analíticos iniciais.</p>

---

## 📝 Descrição da Solução
- Estruturação do modelo dimensional (fatos e dimensões).
- Definição dos principais KPIs logísticos.
- Desenvolvimento de métricas de desempenho para veículos pesados.
- Criação de regras de cálculo para indicadores.
- Validação dos resultados com dados históricos
- Preparação da camada analítica para consumo pelos dashboards.

## 📊 Critérios de Aceitação
- Base de dados integrada, tratada e disponível para consulta.
- O Dashboard deve estar funcional e permitir navegação e visualização dos indicadores principais.
- Consistência entre os dados apresentados e as fontes utilizadas.
- Os dados exibidos devem estar consistentes com as bases utilizadas.
- Disponibilidade dos painéis para suporte à tomada de decisão.
  
---

## 📈 Métricas de Validação
- Taxa de sucesso dos usuários na localização das informações desejadas.
- Tempo médio para navegação e consulta dos indicadores
- Percentual de indicadores carregados sem inconsistências.
- Quantidade de melhorias identificadas durante os testes de validação.
- Precisão dos resultados apresentados em comparação com a base original.
